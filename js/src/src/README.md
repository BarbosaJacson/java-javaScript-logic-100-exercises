Repositório dedicado à resolução de 100 exercícios práticos de lógica de programação, implementados simultaneamente em **Java** e **JavaScript**. 

O objetivo principal desta jornada é consolidar uma base sólida em algoritmos e estruturas essenciais, preparando o terreno para a criação de aplicações mais complexas (como APIs REST ful-stack com Spring Boot e Node.js) e demonstrando maturidade técnica para processos seletivos de desenvolvimento de software.

---

## 🎯 Objetivos do Projeto

- **Fortalecimento de Base:** Dominar os fundamentos de algoritmos, tipos de dados, estruturas condicionais, laços de repetição e manipulação de vetores/objetos.
- **Versatilidade Multilinguagem:** Compreender e comparar como os mesmos problemas de lógica são resolvidos em uma linguagem fortemente tipada (**Java**) e em uma linguagem de script (**JavaScript**).
- **Boas Práticas de Código:** Aplicar convenções de nomenclatura (*camelCase*, *PascalCase*), princípios de *Clean Code* e organização do histórico de commits via Git.
- **Portfólio para Tech Recruiters:** Demonstrar disciplina, consistência diária no GitHub e foco no aprendizado contínuo para conquistar a **primeira oportunidade na área de desenvolvimento**.
